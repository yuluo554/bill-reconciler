## 三、边界与非目标对标（题目 §六）→ 执行方式

| 边界 | 执行方式（机器可查） |
|---|---|
| 不做平台数据库解密/密钥提取/密码破解 | 源码树不含任何解密相关依赖/模块（发布前全仓扫描）；README 与 plan 明示边界 |
| 只解析官方自助导出的账单文件 | 功能集只含文件解析；无任何"数据抓取"通路 |
| 不做投资/理财建议、不做预测 | 报告章节只见"观测结果"；涨价追踪只列已发生的变动（测试断言无预测类输出） |
| 不做云端同步、零上传 | 静态门禁（无网络库导入）+ 运行期无外连断言 + 报告 0 外链；README 隐私声明 |
| 隐私红线（真实数据不入库） | `.gitignore` `_private/` 机制 + 白名单校验（生成器硬门）+ 脱敏扫描（M6） |
| 银行 PDF/OCR/多币种/MCP 不进首期 | plan/04 §八；README 限制节声明扩展项 |
| 品牌隔离 | 文档只谈本项目领域；发布前品牌词族全仓+历史扫描（M6） |
