# plan/00-README 总览

仓库 `10-16-bill-reconciler`（多平台账单"真实支出"对账器）出题与计划总览。v1（2026-10-15，出题阶段骨架落盘）。

**项目**：把微信/支付宝/银行卡导出的账单合并成一本账，自动去重同一笔消费、识别转账/退款/AA回款/自动续费，算出你真正花掉的钱。
**方法论**：ai-tool-project-sprint（数据先行 + 冻结产物 + 合成真值基准 + 确定性规则引擎 + 纯本地交付）。
**交付形态**：**纯本地 Python CLI + 本地 HTML 报告**（无服务器、无 GPU、无联网上传）。
**命名约定**：本地目录 `10-16-bill-reconciler`（`10-16`=2026-10-16 日期标签）；**GitHub 仓库名 = `bill-reconciler`（纯净名，去日期前缀）**，沿用系列惯例 `yuluo554/<kebab-name>`；署名 `yuluo554`（LICENSE/pyproject 一致）。
**定位宣言**：把微信/支付宝/银行卡导出的账单合并成一本账，自动去重同一笔消费、识别转账/退款/AA回款/自动续费，算出你**真正花掉的钱**——全程不出本机。现有工具只做"合并 + 饼图"，**跨平台同一笔消费去重 + 转账语义识别是真空白**（检索 0 结果，见 plan/01 第一节）。

| 2026-10-15 | **弃"云端同步"** | **隐私是本题核心卖点**：账单含真实姓名/账号/消费地点，极敏感。纯本地零上传是定位宣言的一部分，不做云端同步/账号体系/遥测 |
| 2026-10-15 | 交付形态定案：**纯本地 Python CLI + 本地 HTML 报告** | 无服务器、无 GPU、无联网上传。不做桌面 GUI（与系列其他题的形态差异是有意为之：本题卖点是"数据不出机"，CLI + 单文件 HTML 报告最贴合） |
| 2026-10-15 | 首期范围限定为五个模块 | ①多平台账单导入 ②商户名归一化 ③跨平台去重 ④转账/退款/AA回款语义识别 ⑤周期性订阅识别与报告。扩展项：银行 PDF、OCR 长截图、多币种、可选 MCP |
| 2026-10-15 | **语义识别的"未知"是一等结论** | 未命中任何规则的流水记 `未知` 并显式列出，**绝不默认归入"消费"**——否则"真实支出"会虚高，这是本题最忌的假结论 |
| 2026-10-15 | 冻结产物纪律（词表/别名表/参数包） | 关键词表、商户别名表、参数包均为**程序化生成的冻结产物**（配位级守门，禁手改）。一旦可手改，"引擎对不对"就永远无法与"数据对不对"分离 |
| 2026-10-15 | 数值口径一处定义 | 时间窗口、周期参数、重复次数阈值等**只在一处定义**（参数包），识别引擎/报告/基准全部引用同一份；默认值标注"经验默认，非官方" |
| 2026-10-15 | **不做密码破解** | 微信导出 ZIP 的解密**由用户按官方提示自行完成**，工具只处理解密后的 CSV/XLSX。`php-wechat-bill-parser`（9★）专做密码破解，证明该摩擦普遍，但本题**不实现该方向的任何工具**（合规红线） |
| 2026-10-15 | **LLM 使用：不使用** | 纯确定性规则 + 结构化输入（账单文件），无非结构化解析兜底需求（OCR 列扩展项）→ 全链路零 LLM：结论 100% 可复现、零 API 依赖、基准离线可跑、隐私面无外部调用 |
| 2026-10-15 | 核心零第三方依赖（引擎/解析/基准/报告） | 可复现性优先；HTML 报告自写最小 writer（不引模板引擎/CDN）。中文分词（simple）登记为可选辅助，首期不引入 |

## 五、纪律

- **不写会随实现漂移的硬数字**（测试数/用例数/仓库星数以外的实测计数/通过数），指标只写口径与门槛来源；确需数字"以末态回填"。
- **数值口径一处定义**（参数包），注记与文档多处引用，禁止手写第二份口径。
- **冻结产物禁手改**（词表/别名表/参数包/真值台账），改需求走生成器整目录重生成 + `--check` 位级守门。
- **诚实口径**：DoD 里的"CI 绿"在无远端时必须写成"本地等价校验，未接远端，CI 待首推验证"；**未推送 = 未跑 CI**，不得虚报。
- **每个里程碑出口的硬约束**：DoD 验证 → plan/00 状态回写 → 写 `plan/HANDOFF-M<next>.md` → commit →（有远端则 push 等 CI 绿）。
- **品牌隔离**：提及系列其他项目一律用**方向级描述**，不落具体领域名词。
- **隐私红线**：合成样例一律假商户白名单（见 data/README.md）；禁止真实账单/真实商户入库为样例。
