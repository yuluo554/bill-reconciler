# bill-reconciler（多平台账单"真实支出"对账器）

把微信 / 支付宝 / 银行卡导出的账单合并成一本账，自动去重同一笔消费、识别转账 / 退款 / AA回款 / 自动续费，算出你**真正花掉的钱**——全程不出本机。

> 纯本地 Python CLI（≥ 3.8，**零第三方运行时依赖**）+ 单文件 HTML 报告 · 零上传 · 零账号 · 零遥测 · **不使用 LLM**，结论 100% 由确定性规则产生

**当前状态**：M4「内置基准 + 报告」完成（2026-10-15）。CLI 八个子命令全部实装（`import` / `normalize` / `dedup` / `classify` / `report` / `run` / `bench` / `selftest`）；`run --report` 一条命令出**全链产物**（净流水 + 语义 + 订阅 + 单文件 HTML 报告 + 机读 JSON）。内置基准 B1–B4 全绿（指标见下表）。开发进程与交付口径见 [plan/05-里程碑.md](plan/05-里程碑.md)。

## 内置基准指标（B1–B4，门槛随规则包下发）

| 套件 | 口径 | 指标 | 门槛（数据） | 结果（M4 实测） |

| B2 去重 | 真值 5 簇 + 代表笔 + 5 反例 must_not_merge（14 项对账） | 准确率 1.0 / 误报 0 | `accuracy_min = 0.95` / `false_positive_max = 0` | ✅ 达标 |
| B2-r 边界双向对账 | 窗口端点公式推导（引擎）vs 粗扫+细扫穷举恢复（独立路径） | 5 项互验全过（Δt=W 命中 / W+1s 不命中 / 链式传播 / 差 1 分不并 / 划分一致） | 同上 | ✅ 达标 |

## 快速开始

要求：Python ≥ 3.8（开发与 CI 矩阵：3.8 与 3.12）。

```bash
git clone https://github.com/yuluo554/bill-reconciler
cd bill-reconciler

# 免安装直跑（仓库根目录）
python -m bill_reconciler selftest

# 一条命令出结果（净流水 + 语义 + 订阅 + 单文件 HTML 报告）
python -m bill_reconciler run 你的微信账单.csv 你的支付宝账单.csv 你的银行账单.csv --report --report-html report.html --report-json report_data.json

# 内置基准（B1–B4，退出码 0 = 达标）
python -m bill_reconciler bench

# 或安装后使用（console script 两个名字等价）
python -m pip install -e .
bill-reconciler run --help
brc bench
```

> Windows 上如果 `python` 是商店占位符，请用 `py`（如 `py -m bill_reconciler run --help`）。

## CLI 命令（最终态）

`import`（导入）· `normalize`（商户归一化）· `dedup`（跨平台去重）· `classify`（转账/退款/AA回款语义识别）· `report`（HTML 报告）· `run`（一条命令出结果）· `bench`（内置基准）· `selftest`（自检）

退出码契约：**0** 完成无未决 / **1** 完成但检出需人工处理的问题（清单必打印）/ **2** 用法或输入不可用 / **3** 环境不可用（数据目录解析失败等）。详见 [plan/02 §4.5](plan/02-架构与技术选型.md)。

## 隐私与合规（必读）

- **纯本地零上传**：无网络调用、无账号、无遥测；账单与报告全部落本机；
- **不触碰任何平台加密数据库**，不做密钥提取 / 内存 dump，**不实现任何密码破解**——只解析你通过官方自助功能导出的账单文件（微信：我-服务-钱包-账单-常见问题-下载账单；支付宝：账单-开具交易流水证明）。微信导出 ZIP 的**解密由你按官方提示自行完成**；
- 演示与基准数据**全部为程序化合成的假数据**（假商户白名单），**不含任何真实账单**；用户真实账单请勿提交到任何仓库（本仓库已用 `.gitignore` 隔离 `_private/`）。

## 数据来源声明 / 参数来源声明 / 隐私声明 / 免责声明

- **数据来源声明**：本工具不联网获取任何数据；解析对象是**用户自行导出的账单文件**；仓库内样例与基准数据由本项目生成器程序化合成（生成器与种子登记见 `data/README.md` 台账）。
- **参数来源声明**：去重时间窗口、订阅周期参数等可配置值均为**经验默认（非官方）**，集中定义在 `data/rules/` 规则包中，并在报告中显式标注来源；用户可用命令行覆盖（覆盖值同样进报告）。
- **隐私声明**：账单是极敏感数据；本工具零上传、无遥测；用户真实账单不应进入任何仓库。
- **免责声明**：本工具是**个人记账辅助工具**，非财务 / 税务 / 法律工具；输出为基于导出文件的确定性核算发现，不构成任何财务建议或官方认定；解析覆盖度以实际支持的导出格式为准。
