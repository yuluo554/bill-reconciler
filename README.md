# bill-reconciler（多平台账单"真实支出"对账器）

把微信/支付宝/银行卡导出的账单合并成一本账，自动去重同一笔消费、识别转账/退款/AA回款/自动续费，算出你**真正花掉的钱**——全程不出本机。

> 纯本地 Python CLI + 本地 HTML 报告 · 零上传 · 零账号 · 零遥测 · **不使用 LLM**，结论 100% 由确定性规则产生

**当前状态**：出题阶段骨架已落盘（题目定稿 + 项目计划启动）。开发从 **M1 数据先行** 开工。

- 题目全文见 [plan/01-题目文档.md](plan/01-题目文档.md)；
- 计划总览（决策记录 / 承诺-证据台账 / 里程碑）见 [plan/00-README总览.md](plan/00-README总览.md)；
- 数据纪律与依据查证见 [data/README.md](data/README.md)。

**边界（必读）**：本工具**不触碰任何平台加密数据库、不做密钥提取/内存 dump**，**只解析用户通过官方自助功能导出的账单文件**（微信：我-服务-钱包-账单-常见问题-下载账单；支付宝：账单-开具交易流水证明）。微信导出 ZIP 的解密由用户按官方提示自行完成，**工具不实现密码破解**。详见 [plan/01](plan/01-题目文档.md) §六。
